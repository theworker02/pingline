Overview

Ping CSV/TSV line tables for quick inspection and cleanup. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/pingline.git
cd pingline
node src/cli.js --help
node --test
