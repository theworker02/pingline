# pingline

Ping CSV/TSV line tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/pingline/

## Install / run

```bash
git clone https://github.com/theworker02/pingline.git
cd pingline
node src/cli.js
node --test
```
